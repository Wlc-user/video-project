## 🚀 快速启动

### 1. 启动服务
```bash
cd backend
python -c "import uvicorn; uvicorn.run('main:app', host='0.0.0.0', port=8000, reload=True)"
```

### 2. 访问上传页面
- 浏览器打开：http://localhost:8000/api/upload/

### 3. 使用步骤
1. 拖拽或选择视频文件（支持MP4/AVI/MOV/MKV等）
2. 选择分析类型和语言
3. 点击"开始分析"
4. 查看AI分析结果

## 🔧 技术架构

### 上传流程
```
用户上传 → 前端页面 → 后端接收 → 本地存储 → 生成临时URL → AI分析 → 返回结果
```

### 存储方案
1. **当前**：本地存储（成本最低）
2. **扩展**：可升级到云存储（阿里云OSS/腾讯云COS）
3. **容量**：自动清理，7天保留期

### 流量控制
- 基于用户IP的限制
- 每日使用次数限制
- 文件大小限制（500MB）

## 🆘 故障排除

### 常见问题
1. **上传失败**：检查文件格式和大小限制
2. **分析失败**：检查AI服务是否正常
3. **页面无法访问**：检查服务端口是否被占用
4. **存储空间不足**：运行清理脚本

### 维护命令
```bash
# 清理过期文件

# 查看系统状态
```
