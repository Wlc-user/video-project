# 支付宝支付接入指南

## 快速开始

### 1. 安装依赖

```bash
cd backend
pip install alipay-sdk-python==4.11.8
pip install python-dotenv
```

### 2. 复制配置模板

```bash
cp .env.example .env
```

### 3. 修改 `.env` 文件

填入你的支付宝配置参数。

---

## 支付宝配置步骤

### 第一步：注册支付宝开放平台账号

1. 访问 [支付宝开放平台](https://open.alipay.com)
2. 使用企业/个人支付宝账号登录
3. 完成开发者认证

### 第二步：创建应用

1. 进入「控制台」→「我的应用」
2. 点击「创建应用」
3. 选择「自研应用」
4. 填写应用信息

### 第三步：获取配置参数

在应用详情页获取：

| 参数 | 位置 | 说明 |
|------|------|------|
| `APP_ID` | 应用信息 | 格式：2021000112345678 |
| `ALIPAY_PUBLIC_KEY` | 密钥设置 | 下载「支付宝公钥」 |

### 第四步：配置密钥

#### 4.1 生成应用私钥

```bash
# 生成私钥
openssl genrsa -out app_private_key.pem 2048

# 转换为PKCS8格式（支付宝要求）
openssl pkcs8 -topk8 -inform PEM -outform PEM -nocrypt -in app_private_key.pem -out app_private_key_pkcs8.pem

# 查看私钥内容
cat app_private_key_pkcs8.pem
```

#### 4.2 上传公钥到支付宝

1. 在「密钥设置」页面
2. 点击「设置应用公钥」
3. 粘贴公钥内容

### 第五步：配置回调地址

1. 在应用设置中配置「回调地址」
2. 必须使用 HTTPS
3. 地址：`https://你的域名/api/payment/alipay/notify`

### 第六步：沙箱测试

开发阶段使用沙箱环境测试：

1. 访问 [沙箱](https://open.alipay.com/platform/appDaily.htm)
2. 下载「支付宝沙箱」App
3. 在 `.env` 中设置 `ALIPAY_SANDBOX=true`
4. 使用沙箱账号登录测试

## 生产环境部署

### 必需条件

1. ✅ 已完成开发者认证
2. ✅ 已签约支付产品
3. ✅ 域名已备案
4. ✅ 已配置 HTTPS

### HTTPS 配置

```nginx
# Nginx 配置示例
server {
    listen 443 ssl;
    server_name yourdomain.com;
    
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    location /api/payment/alipay/notify {
        proxy_pass http://127.0.0.1:8000;
    }
}
```

## 常见问题

### Q: 签名验证失败

检查：
1. 私钥格式是否正确（PKCS8）
2. 公钥是否与私钥匹配
3. `ALIPAY_PUBLIC_KEY` 是否包含头尾标记

### Q: 回调地址无法访问

1. 确保使用 HTTPS
2. 确保服务器公网可访问
3. 检查防火墙/安全组配置

### Q: 沙箱与生产切换

```bash
# 沙箱模式
ALIPAY_SANDBOX=true

# 生产模式
ALIPAY_SANDBOX=false
ALIPAY_GATEWAY=https://openapi.alipay.com/gateway.do
```

### Q: 资金没有到账

1. 检查支付宝商户平台交易记录
2. 确认应用已签约相关产品
3. 查看后端日志的回调处理结果

## 安全建议

1. **不要**将私钥提交到 Git
2. **不要**在代码中硬编码敏感信息
3. **必须**验证回调签名
4. **建议**记录完整支付日志
5. **建议**设置支付金额上限
